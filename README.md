Linux Quest Game 🐧⚔️
Welcome to Linux Quest, an interactive terminal-based adventure designed to turn the complexity of Linux command-line mastery into an engaging quest. Whether you are a "Newbie" squire or a "Root" legend, this game challenges your skills in navigation, file management, and system administration.

✨ Features
Progressive Difficulty: Start with basic commands like ls and cd, and work your way up to complex permissions and networking.

Interactive Challenges: Solve puzzles by manipulating real files and directories within a sandbox environment.

Instant Feedback: Get immediate hints or success messages as you complete each quest objective.

🛠 Prerequisites
To run this game, you will need:

A Linux-based environment (Ubuntu, Debian, Fedora, etc.) or macOS.

Python 3.x installed on your system.

Basic familiarity with opening a terminal.

🚀 Installation
Clone the repository to your local machine:

Bash
git clone https://github.com/poly9630/linux_quest-game.git
cd linux_quest-game
🎮 How to Play
Start the Quest: Run the main game script using Python:

Bash
python3 main.py
Follow the Prompts: The terminal will describe your current "room" or challenge.

Execute Commands: Use your Linux knowledge to solve the task described.

Advance: Once the task is completed, the next level will unlock.
